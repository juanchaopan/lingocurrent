# 已确认的解释卡、收藏与复习词卡刷新规则

状态：用户于 2026-11-15 最终接受当前方案。直接要求与“AI 建议，用户默认”的来源仍保留，以下行为为有效规格。

## 用户已经明确的规则

- 查词解释缓存与复习词卡独立；删除复习词卡和复习记录不删除解释缓存。
- 解释卡当前内容被主动收藏后，复制为生词卡，不因后续查词刷新自动被改写。
- 当前查词含义已对应个人词库里的某个词义时，刷新不能切换词义，可以换例句。
- 生词详情允许换例句，但词义不能变。
- 四个 Translate 选项最初要求在加入生词本时生成。用户认可“需要同时生成时合成一次请求”的思路，没有明确要求每次未收藏的查词刷新也提前生成四选项。
- 刷新失败什么都不修改。重复收藏确认替换时保留三种复习进度。

## 最终行为（AI 建议，用户默认）

| 操作 | 解释缓存 | 已收藏复习词卡 | Translate 选项 |
|---|---|---|---|
| 文章或例句里的解释卡刷新 | 固定当前词义，更新例句与目标位置；若已匹配现有词义，继续用该词义 | 不自动改变 | 未收藏时不预生成 |
| 点击加号首次收藏 | 不因收藏而改变缓存 | 保存当前显示的规范词、中文和例句 | 在收藏时生成四项 |
| 重复收藏并确认替换 | 不额外改变缓存 | 替换中文解释和例句，保留进度 | 检查与保存内容一致；确需重建时合并生成并一起保存 |
| 在生词详情主动刷新例句 | 不反向覆盖文章解释缓存 | 换例句并保持词义、进度 | 词义/词性/答案未改变时复用现有四项；确需同步更新选项时合并生成 |
| 任何刷新失败 | 保留旧值 | 保留旧值和进度 | 保留旧选项，不部分写入 |

前四行的更新边界随最终方案获接受；失败不改此前已由用户明确认可。固定词义只换例句时不重建四选项，不为解释刷新新增自动改写生词卡的联动。

## 请求数量和 token 的区别

同一次生成例句和四选项可以减少网络往返，并可能避免重复发送相同输入上下文；不能仅凭请求数量减少，就断言总 token 更少。额外输出四选项仍产生输出 token；若用户只查词而没有收藏，提前生成的选项可能没有用途。[OpenAI 官方价格说明](https://developers.openai.com/api/docs/pricing)

因此推荐：未收藏的解释卡只生成需要的解释与例句；加入生词本时生成选项。词义固定、仅替换例句时，既有选项仍可能有效，不必无条件重生成。需要连同选项更新时，再一次生成、验证后一起保存。
