## D/E 建议最终状态

D-001–D-016 按 review-defaults.md 的最终版本采用，保留 AI 来源。其中用户直接纠正的缓存、频道、录音和验证分工优先于旧建议。

| 编号 | 原补充来源 | 最终状态 |
|---|---|---|
| E-001 | 0 起始、常量表索引、七次/59 天推算 | 接受轮次 0 的表示；索引/终点留 Design。七次/59 天不作为独立硬约束，不擅自声称是用户直接指定。 |
| E-002 | 所有新频道套同一时区/频率/篇数，全站固定 16 篇 | 撤回。每频道时区、每时点篇数独立，数据库配置和执行记录由用户明确；不同 URL/RSS 独立频道的建议已接受。 |
| E-003 | 错误/空状态、重试、故障不计错、旧值保护、AI 数据校验 | 采用。失败不改由用户直接认可，其余为 AI 建议用户默认。 |
| E-004 | 防重复推进、跨设备一致、删除不复活、网络未保存提示 | AI 建议用户默认；具体工程机制留 Design。 |
| E-005 | Secrets/Variables、服务端注入、稳定词义标识、目标位置表示 | 采用工程方向；具体技术设计不由 kickoff 先锁死。 |
| E-006 | 录音对照、测试文本、音色比较、时长/用量测量 | 作为起始验证计划采用，用户选择实际音色；尚未执行。 |
| E-007 | 费用看板/报告及数据库记录、负载配比 | 不做费用看板，数据库记录是用户明确要求；负载配比留 Architecture / staging。 |
| E-008 | 生词详情仅换例句时进度不变 | 最新推荐方案已接受；缓存、词卡互不自动覆盖。 |
