# 产品愿景

状态：已确认，kickoff 完成，2026-11-15（America/Toronto）。用户明确要求与最终接受的 AI 补充保持来源区分，详见 provenance-review.md。

## 一句话

LingoCurrent 是一个面向受邀英语学习者的响应式网站，将每日英文文章、逐句听读、语境查词与三种独立间隔复习连接成可持续使用的学习流程。

## 目标用户

| 角色 | 是谁 | 现在怎么解决 | 痛点或目标 |
|---|---|---|---|
| 学习者 | 项目所有者及受邀用户；一年内最多 1,000 人 | 现有工具和使用习惯未提供，不作推断 | 在同一处完成听读、查词、收藏与复习；手机和平板也能使用 |
| 项目维护者 | 通过 Clerk/部署配置维护邀请名单、内容来源与部署，不另建首版运营后台 | 尚无应用代码或既有系统 | 在 Vercel、Neon、Clerk 和 OpenAI 约束下维护服务并控制成本 |

## 成功标准

- 第一版完整覆盖用户描述的阅读、选词解释、收藏、三个复习模式及 Archive，而非仅交付其中一部分。
- 每个资源频道有自己的采集时间表；00:00、06:00、12:00、18:00 是示例频道配置，此前每批 4 篇的目标保留，新增频道篇数待定。正文与完整音频均就绪后才发布，不把全站日总量固定为 16 篇。
- 在电脑、平板、手机上走通文章 → 逐句播放 → 拖选查词 → 收藏 → Speak / Spell / Translate → Archive 的完整流程。
- 规范词形、词义复用、例句高亮/挖空、独立查词缓存、刷新与收藏分离、删除词卡保留解释缓存、错后保留轮次等规则通过对应验收。
- 设计容量为 1,000 个受邀账号、100 人同时使用；月度总费用期望 30 美元，但不得因超过该金额限制任何用户使用。实际调用成本和容量仍须测算，不把目标写成已验证承诺。
- TTS / 音色在独立试听 spike 给用户几个 demo 选择；发音判定、选词、句子同步及性能在正常 staging 验证，D-014 不做 spike。
- 后台和锁屏播放在设备/浏览器支持时实现；Speak 原始作答录音不长期保存。费用和用量入数据库，不做费用看板。

## 范围

### 第一版（MVP）

- 邀请制 Google 登录、独立个人学习数据：REQ-001–REQ-002。
- 定时采集、多类别正文存储和朗读音频：REQ-003–REQ-005。
- 最新文章、阅读历史、全文搜索、逐句与跨文章播放：REQ-006–REQ-011。
- 跨行选词、原形与词义解释、个人缓存、嵌套浮层、例句定位：REQ-012–REQ-016。
- 收藏、替换确认、四选项生成、生词列表、详情和删除：REQ-017–REQ-021。
- Speak、Spell、Translate 及独立间隔和错后重练：REQ-022–REQ-027。
- 状态持久化、指定服务配置、异常处理、规模预算与 staging 验收：REQ-028–REQ-032。
- 设备支持时的后台/锁屏播放、数据库用量与费用记录：REQ-033–REQ-034。

### 以后再做

暂未确认任何从首版延期的已提功能；不得以预算或复杂度为由自行移出范围。后续新增能力另行评估。

### 明确不做

- 采集文章图片：用户明确只采集正文。
- 单独重置 Speak、Spell 或 Translate 进度：用户明确禁止。
- 额外独立模型计算服务器：用户限定 Vercel 计算环境。
- D-014 的独立性能 spike：用户明确不需要。TTS 试听是用户指定的例外，单独开展。
- 费用看板：用户明确不需要，但数据库必须保存相关记录。
- 支付、社交、原生手机应用、离线包和数据/字幕导出不列入首版。后台播放已进入条件性实现目标。

## 约束

| 类别 | 要求 | 来源 |
|---|---|---|
| 规模 | 一年内最多 1,000 人，峰值同时使用 100 人 | 第七轮 |
| 内容量 | 每频道自定时区及时间表，每个时点单独指定篇数；数据库记录配置和每次执行；具体值待选 | 对 D/E 的最新回答 |
| 界面 | 全英文 UI，词义和题目学习内容包含中文；电脑、平板和手机 | 初始描述 |
| 身份 | Google 登录，Clerk 为用户身份来源，邀请制 | 初始描述、第一轮 |
| 数据库 | Neon | 初始描述 |
| 部署 | Vercel；不接受额外计算环境 | 初始描述、第七轮 |
| AI | 云端 AI API 使用 OpenAI，低成本优先；允许本地模型，是否适用需验证 | 第二、三、七轮 |
| 密钥 | GitHub 管理配置，各环境共用一个 OpenAI key | 初始描述、第二轮 |
| 费用 | 全部服务每月合计以 30 美元为期望；不设按该金额的使用上限或停用规则 | 第八轮覆盖第七轮预算口径 |
| 时间 | 既有时区 America/Toronto，示例频道 00:00、06:00、12:00、18:00；各新频道独立配置；无硬上线日期 | 第二、七、八轮及最终核对 |
| 验证 | TTS/Speak 分别候选 spike，Speak 测真实 Vercel Hobby；完整交互/集成及 D-014 性能留 staging | 最新架构回答覆盖早期仅 TTS spike 的方向 |
| 性能 | 正常网络下 P95 列表/已生成正文 3 秒、AI 查词/判音 10 秒为初始目标；staging 实测，非已测承诺 | AI 建议，用户默认（最终确认） |
| 可用性 | 重试、检查点与事务/版本比较保持业务一致；架构已定稿，99.5% 为目标，Free 恢复保障较弱 | 架构 overview、ADR-0013/0015；尚未实测 |
| 数据保留 | Neon 音频按创建时间 FIFO、95%/90%；删文章当前音频同时删文章/访问记录。例句只删音频、文本留表、下次点击重建。全部个人解释文本/词卡/例句/复习保留；任务成功即删，原始录音不长期保存。Neon Free 弱恢复，不保证原 24 小时 RPO/RTO | 用户最终确认；ADR-0003/0005/0007/0013/0015 |

## 假设与待验证事项

- 尚未证明自然 TTS、语音判定、100 人并发及全部服务的费用能接近 30 美元期望，需要测算实际活跃率、调用量和解释重复生成情况；不以限额停用替代成本测算。
- 尚未确认最终文章来源清单；“可浏览”或“有 RSS”不直接等于可保存全文并制成音频。
- 尚未验证手机跨行选词、嵌套浮层和各设备音频行为。
- 尚未证明候选语音对用户口音、低频词和近音错词可靠；TTS、Speak 分别做候选 spike，Speak 验证真实 Vercel Hobby 适用性，完整集成与 D-014 留 staging。
- 1/2/4/7/15/30 天及错后 10 分钟是用户选择的产品规则，不宣称为普适最优记忆算法。
