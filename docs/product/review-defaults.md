# 已确认的补足规则

状态：已确认。来源为“AI 建议，用户默认（2026-11-15 最终确认）”，并保留用户直接修正的优先级。这些规则与 requirements.md 一起构成 kickoff 交付；不将建议的来源改写成用户最初亲口指定。

| 编号 | 最终规则 |
|---|---|
| D-001 | 通过 Clerk 或部署配置维护邀请名单，首版不另建运营后台；未登录仅进入登录页，受邀用户才能进入学习功能。 |
| D-002 | 全站共享文章、正文、TTS 音频及时间轴；个人阅读记录、解释缓存、生词及复习数据隔离。 |
| D-003 | 文章按采集时间倒序并保持稳定并列顺序。列表连续播放采用启动时当前搜索/列表的全部匹配项，跨分页固定队列；新发布文章下次启动加入。 |
| D-004 | 点例句播放才暂停文章；例句结束或关闭浮层后，文章保留位置并等待用户手动恢复。 |
| D-005 | 支持跨视觉行及相邻句子的连续选区，按相关句子提供上下文。点击空白或桌面 Escape 返回上一层；隐藏目标词不可跨越。 |
| D-006 | Speak / Spell 作答前不提供会直接读出隐藏目标答案的完整例句音频；其他可见词仍可解释收藏，不因查其他词额外扣分。 |
| D-007 | 解释卡刷新只改个人解释缓存，生词详情刷新只改该复习词卡；固定词义仅换例句时复用四选项。确需重建选项时可合并请求，完整成功才保存，失败什么都不改。详见 refresh-behavior-proposal.md。 |
| D-008 | 三个主按钮 Speak / Spell / Translate，各显示 due/new 数量；All / Due / New 筛选默认 All。最早到期优先，再处理新词。会话中新收藏词下次加入，已到期短练可重新入队。活动列表按三个未完成模式最早到期排序，新词独立标记，不设每日学习额度。 |
| D-009 | 删除生词卡、关联题目和全部复习记录并移出队列，不删除解释缓存。重新收藏建立三个模式均未开始的新词卡。Archive 可查看和删除，不提供单模式重置或恢复进度入口。 |
| D-010 | Spell 忽略首尾/多余空格及非词义区分的大小写，接受适用的规范英美拼写；不把其他同义词或不符合规范形式的屈折写法当作目标答案。允许形式由 AI 提供，无需用户手工配置。 |
| D-011 | lyrics 指句子同步时间轴，供点播、高亮与进度定位；首版不另做字幕文件导出。 |
| D-012 | Neon 缓存文章/例句音频，创建时间 FIFO、95% 触发清至低于 90%。文章当前音频淘汰时同时删文章、正文/句子/时间轴及访问记录；例句只删音频，例句留表，下次点击朗读重建。全部个人解释文本/词卡/例句/复习保留。删卡不删解释缓存，Speak 原始录音不长期保存。后台/锁屏按支持实现，无离线包/导出；ADR-0005/0007/0015。 |
| D-013 | 每个时点按配置篇数采集不同新文章，正文/音频均就绪后逐篇发布。不足时如实少发，不用重复或未就绪文章补数；失败下批优先重试，重跑幂等。重试次数和补跑机制留 Design。 |
| D-014 | 正常网络下列表/已生成正文 P95 3 秒内可读，AI 查词/判音 P95 10 秒内返回，作为起始设计目标。性能在 staging 测量，不做独立性能 spike；这些不是已测结果。 |
| D-015 | Speak 以本人 10 正确、10 错误及至少 3 无效录音作起始测试；正确/错误各至少 9/10 判对，无效录音不通过且可重录。TTS 同文 3–4 段 demo 对比至少两个候选，由用户选择，4/5 主观评分仅作参考。最新架构选择为 TTS/Speak 分别候选 spike，Speak 测真实 Hobby；完整集成及 D-014 留 staging，小样本不代表所有词/口音可靠。 |
| D-016 | 不同内容 URL/RSS 分为独立资源频道，归属同一来源分组，例如 Yahoo 科技和 Yahoo 娱乐；每频道有自己的时区，每个采集时点有自己的篇数。配置、计划和运行记录存数据库，实际结构留 Design。 |

## 轮次与常量表

用户明确记录已完成轮次：第一次成功完成为 1，第二次为 2；三个模式独立。初始未开始用 0 表示。统一常量表完整包含 1、2、4、7、15、30 天的等待安排，完成其全部阶段后该模式完成；错后短练成功不增加轮次，重新等待原间隔。

表的键、索引及终点字段留 Design 确定。早期“七次/59 天”是 AI 给出的映射推算，不另作为写死的业务约束；实现不得少走已约定的等待阶段。
