代码、文档和对话统一使用以下叫法。具体数据字段和实现由架构阶段确定。

| 术语 | 英文 | 含义 | 不要混用为 |
|---|---|---|---|
| 原文词形 | Surface form | 用户在原句中实际选中的写法，包括屈折变化 | 规范词形 |
| 规范词形 | Lemma / canonical form | AI 按语境自动返回、用于查词卡标题和收藏的词典形式，如动词原形或名词单数 | 机械删掉词尾，或由用户手动配置的词形 |
| 词义 | Sense | 结合词性和语境区分的语义身份；“声音／声响”不因译法不同自动成为不同词义 | 中文解释字符串 |
| 查词解释缓存 | Lookup cache | 某用户在某句某选区的AI解释与所属例句集合，相同句子/选区跨来源复用；例句关联lookup ID，可逐个切换；独立于生词本，删除词卡不删除它 | 已收藏词条、全局单词例句库或随词卡删除的数据 |
| 生词条目 | Vocabulary entry | 某用户收藏的规范词/短语、词性、词义、中文、原句/范围及自己的多条例句，例句关联词卡ID，复习可逐个切换 | 每次查词自动收藏、共享可改缓存例句或版本历史 |
| 目标词位置 | Target spans | 目标词或短语在例句中的实际位置，用于解释卡高亮和复习卡隐藏 | 仅匹配原形的一次字符串替换 |
| 拼写复习 | Spell | 根据中文、词性和挖空例句填写英文规范词形或短语 | 默认只听录音的听写 |
| 口语复习 | Speak | 根据中文、词性和挖空例句，说出英文规范词形或短语；本地判定需验证，必要时使用 OpenAI | 将语音转写相等直接视为发音正确 |
| 翻译复习 | Translate | 根据英文目标，从四个带词性和中文含义的选项中作答 | 首次做题时才生成选项 |
| 轮次进度 | Review round | 某词卡某mode的当前round，可升降；答对+1，答错−1且最低0；不是历史累计成功数 | 只增不减的累计答对次数 |
| 轮次间隔常量表 | Review interval table | 统一定义答对后所得轮次的等待时间及终点 | 每个词条分别写死的一串日期 |
| 阶段间隔 | Stage interval | 正常到期之间等待的天数：1、2、4、7、15、30 | 自加入日期起的累计第几天 |
| 到期复习 | Due review | due_at≤当前时间的词可作答；不区分正式/短练 | 尚未到期也可提前提交 |
| 错后再答 | Retry after an incorrect answer | 答错减轮但最低0，due_at推到本次提交10分钟后；下次正确仍统一加1 | 额外的短练状态或不加轮分支 |
| 已归档 | Archived | 某条目 Speak、Spell、Translate 全部完成 | 只完成一种模式 |
| 删除词卡 | Delete vocabulary entry | 删除该词卡和全部复习记录，不再把该词义作为生词本信息提供给 AI；独立解释缓存保留，重复上下文仍命中 | 删除查词解释缓存，或单独重置一个模式 |
| 资源频道 | Resource channel | 用户明确要求有独立采集时间表的内容采集单位；具体频道清单和话题未定 | 全站只能有一个统一采集时间表 |
| 采集批次 | Collection batch | 某资源频道按自己时间表触发的一次采集；现有示例为 00/06/12/18 时，每批曾指定 4 篇，新频道配额未定 | 全站每天必然且只能 16 篇 |
| 月费用期望 | Monthly cost target | 所有服务每月约 30 美元的优化目标，超过后仍允许所有用户继续使用 | 硬预算、使用额度或自动停用阈值 |
| 采集时间计划 | Collection schedule | 某频道时区内的执行时点及该次要采的篇数；同频道不同时点可以配置不同篇数 | 全频道共用单一篇数或全站共用时间表 |
| 临时采集任务 | Channel collection job | 按频道计划到点创建，必要时含多篇文章临时明细；正文和音频任务可靠保存后删除任务/全部明细，2026-11-16澄清原意 | 永久采集运行记录或完成任务归档 |
| 原始作答录音 | Raw speaking recording | 用户在 Speak 题中录下并提交判定的声音，不长期保存 | 需要保存供听读的 TTS 文章/例句音频 |
| 用量与费用记录 | Usage and cost record | 存入数据库的调用用量及费用相关信息，不提供费用看板；字段留 Design | 不受控使用上限或面向用户的新费用页面 |

本表已于 2026-11-15 随 kickoff 最终确认；词义、缓存、频道与轮次业务含义已经明确，具体字段和实现交 Architecture / Design。
