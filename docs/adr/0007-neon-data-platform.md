# ADR-0007 Neon 数据库及对象存储，应用计算在 Vercel

- 状态：已接受
- 日期：2026-11-15
- 相关需求：REQ-003–REQ-005、REQ-010、REQ-014、REQ-020、REQ-029–REQ-031、REQ-034

## 背景

用户希望数据集中在 Neon，应用功能运行在 Vercel，并要求核对免费额度。例句音频也进入可淘汰缓存，写入次数会增加。数据库已选 Drizzle/Zod，临时任务表与 95%/90% FIFO 已接受。

## 候选方案

| 方案 | 优点 | 缺点 | 适合条件 |
|---|---|---|---|
| Neon Postgres + Neon Object Storage | 数据集中；对象免费 5 GB，无另列对象操作计费 | 免费公共出网 5 GB/月与数据库共用，分支/删除释放需验证 | 用户本轮直接选择 |
| Neon + Vercel Blob | Vercel SDK/CDN 集成直接，Blob 下载免费 10 GB/月 | 对象 1 GB、高级操作 2,000/月，缓存写入可能先触限 | 播放流量较重要且写入少 |
| Vercel Marketplace Prisma Postgres | 免费数据库 2 GB，可从 Vercel 接入 | 改变现有供应商、查询操作上限；仍需另选音频对象存储 | 本轮未选 |

## 决策

用户明确选择 Neon Object Storage 与 Vercel-managed Neon。数据库创建/绑定和管理入口通过 Vercel，底层为 Neon；音频使用 Neon 私有对象存储，Vercel 服务端通过 S3 客户端访问。应用计算继续在 Vercel，不启用 Neon Functions、Auth 或 AI Gateway 替换既定组件。

音频包括文章与例句缓存，沿用 ADR-0005 的创建时间 FIFO、95%/90% 及个人数据保留边界。Neon Free 当前对象预算以 5 GB 为参考，示例水位约为 4.75 GB/4.5 GB，实际以所建项目条款和计量范围为准。

数据库元数据、临时任务、音频是同一平台下不同资源。SQL 事务不假定包含 S3 上传/删除，保留完整上传后再事务提交引用/可见状态、幂等恢复、孤儿清理与任务成功删除的机制。

根环境凭据按 GitHub Secrets/Variables 管理并注入 Vercel；集成自动绑定 DB URL 的能力不等于已自动绑定对象存储全部凭据。通过授权检查后发放短期音频链接，验证 Range、缓存与真实设备后台播放。

## 证据

用户本轮明确选择。官方依据及比较见 [数据库](../architecture/database-options.md)、[对象存储](../architecture/object-storage-options.md)。公开文档证明产品能力与额度，不是实际项目部署、计量或删除释放的测试结果。

## 后果

- 好处：数据与文件供应商统一，例句缓存写入避免 Vercel Blob 的小额高级操作配额。
- 代价：5 GB/月共享出网可能先耗尽，压缩/缓存不保证目标规模全部免费；对象分支与回收计量、数据库恢复后的资产核对必须验证。
- 重新考虑条件：实际流量或释放行为不适用、播放延迟不达标、免费容量不足。不得擅自开付费、迁移供应商或扩大个人数据删除范围。
