# ADR-0019 复习只存轮次和到期时间

- 日期：2026-11-16。
- 状态：已接受，用户明确“ok, finalize design”。
- 相关：REQ-019、022、026–028、037；修订ADR-0015/0018的复习实现，不改变技术栈或模块边界。

用户要求取消phase和session，错误round减1、due_at推10分钟，再错再减，最低0；正确round+1并查1/2/4/7/15/30天间隔，终点清due_at。随后用户确认不保留prompt或attempts表，复习只存review_progress。

每次取题实时查询到期与未开始词，先到期后新词；从当前词卡生成脱敏题面直接返回，不写题目或答案快照。提交从数据库取当前答案，锁卡/进度检查当前可答条件，正确/错误只更新该mode进度，与已有通用mutation_receipts的提交状态同事务。无session、cohort、phase、is_retry、业务版本或逐次成绩历史。

通用operationId在24h可配置窗口内去重，重试确认已保存并重读当前进度，不复制答卷/判定到receipt，也不承诺重放原判定。窗口外不自动重放；并发不同操作通过行锁及due_at/终点复核拒绝紧接的重复推进。不承诺冻结旧题、永久答卷去重或恢复历史。正确答案始终从服务端当前词卡取得，技术失败不计错。

round现在可回退，因此使用round而非completed_rounds。2→错1→对2可回原轮；连续错会逐轮退，0不再减。0且due为空才new，有due已经开始。原独立短练保轮规则及0轮未决分支撤回。

保留现有文章播放队列与列表临时快照，不将它们误当复习session删除。详细逐步读写及验证见[复习示例](../design/stateless-review.md)。尚无应用/数据库迁移或真实并发测试。
