# LingoCurrent mockup源码

2026-11-16复习精简：模拟进度只存round和相对到期分钟数，New/Complete均派生；去掉phase/Practice及固定批次题数。正式规则以data-model和stateless-review为准；此预览仍不保存真实成绩。

已确认的当前源文件：`lingocurrent-input-design.html`，包含Mouse & keyboard、Phone touch、Tablet touch三种布局的全部HTML/CSS/交互脚本。此文件是仓库内权威副本；聊天展示目录只保留它的相同内容镜像，后续修改先更新仓库副本。

`archive/lingocurrent-initial.html`保存最初展示稿，已被当前规则取代，仅供历史追溯。生成各轮修订时的一次性编辑脚本不是运行依赖，未纳入产品源码。

这些HTML为聊天预览使用的片段，外层轮播和Lucide图标由预览宿主提供；直接用普通浏览器打开不等价于宿主预览。所有产品样式和业务交互演示源码均在文件内，没有调用RSS、Clerk、AI或真实音频接口；词条和删除只是本次预览的虚构数据。

验证生成内容和状态转换：在仓库根运行 `node docs/design/mockups/check-mockup.cjs`。仅使用Node内置模块，覆盖分页/连续加载互斥、选择后删除/取消、末页、侧滑露出、长按选择、模式字与关闭同行、空访问时间、详情无删除。它不验证浏览器排版、原生手势/读屏、鉴权或数据库事务。

触控操作：向左滑卡片，右侧露出红底Delete；长按或点Select进入选择模式。前者在预览源码中已有实现，不是因Design阶段无法制作而用词头旁按钮代替。未在真实设备上验收时，应明确保留此工程验证项。

最新交互：触控文章/词卡可点整张item，桌面仅标题/词头进入；独立操作与选择模式不跳详情。词卡详情用X关闭并恢复原词库查询/位置，文章返回同样保留列表上下文。Node检查覆盖这些状态分流及滑动/长按/竖滚误触抑制，仍不替代真实命中区域和原生手势验收。

例句切换：缓存浮窗、词卡详情及三模式复习均有独立的本地显示索引。电脑句子两侧箭头，手机/平板横滑并保留可访问按钮，下方1 / N；单项/首末禁用、不循环。Resilient样本有两句，其他词有单句状态。收藏复制完整例句数组；取消重复收藏确认不提前修改词卡，刷新只改当前可见例句。Node执行箭头/键盘/模拟touch/pen事件、边界、选择/竖滚不误翻、拼写输入与翻译选项保持、两种例句独立及Speak/Spell切换后的目标隐藏；没有浏览器渲染/真机/音频或DB验证。
