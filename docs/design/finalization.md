## 最终决定

当前权威规格为experience.md、data-model.md、api-contracts.md、state-machines.md及stateless-review.md。用户逐项修正及本次最终确认优先于访谈、历史设计记录和初稿。

1. 鼠标紧凑分页表格、手指卡片连续加载，平板按输入与空间适配；共享数据/服务。导航、字号、列头筛选/排序、点击区域、侧滑/多选删除、账号退出和复习关闭均已收敛。
2. Articles唯一列表及最后访问时间；固定顺序跨文章/跨页连续播放，篇末回列表再进下一篇，无列表播放条。
3. Lookup与词卡分别拥有多条例句，收藏复制整组；每次显示一条，横滑/箭头及1 / N切换，显示索引只在页面；同用户同句同范围跨来源复用Lookup。
4. 没有业务版本、lexeme辅助表或current_example_id。Source/Channel/计划稳定配置；临时频道任务及明细完成全部删除。
5. 复习只保留review_progress。删除session两表、prompt和attempts表；无phase/is_retry。错误round减1最低0、due延10分钟，正确加1查间隔，终点完成。发题只读当前词卡直接返回脱敏题面；判定从服务端当前数据读取答案，进度行锁及已有通用operationId防窗口内重复修改。
6. 通用去重以24h为可配置初值，不保存原答卷/原判定或学习历史，不承诺永久重放或旧题恢复。语音技术故障不计错；关闭回Vocabulary，已提交不撤销。
