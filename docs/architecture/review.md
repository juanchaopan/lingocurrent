## 漏洞检查结果

| 检查项 | 发现的风险 | 已设计措施/代价 | 剩余证据或接受边界 |
|---|---|---|---|
| 人力/过度设计 | 一人维护多服务或两套队列成本高 | 模块化单体、DB 任务/全文检索，不另加 Queue/Redis/搜索服务 | 当前无独立扩容证据，暂不拆分 |
| 多实例/进程状态 | 进程内锁/缓存不能保证幂等 | DB 计划键、租约/fencing、版本、操作 ID；本地双副本验证 | 实现后做真实 DB 竞争/崩溃测试 |
| 发布事务 | 抓到文章后未入队即崩溃；上传后未发布 | 文章+任务原子写；不可变对象，条件发布+删任务原子提交；孤儿对账 | 检查各崩溃点，不宣称外部模型恰好调用一次 |
| 顺序/兼容性 | 重复唤醒、租约旧 worker、任务跨版本 | payload 版本、检查点、截止时间；新旧应用兼容迁移 | staging 回滚及旧任务恢复验证 |
| 个人数据竞争 | 删除中迟到 AI 结果/重复成绩复活或双推进 | 应用事务锁/重查、存在检查、不 upsert、通用operationId去重；删关联记录同事务 | 词义集合并发变化/跨设备复习专项用例 |
| 时钟/计划 | DST、不同实例时间、重复时点 | IANA 时区配置、DB UTC、唯一计划运行键；DST 规则在 Design 明定 | 频道配置前确认具体时点，测试 DST 边界 |
| 网络/背压 | 来源/AI 拖满函数，重试风暴 | 超时、有限退避、并发控制、任务检查点，事务不跨 AI | 参数基于 spike/staging 调整，无个人月度额度 |
| 存储删除/恢复 | SQL/S3 非原子、软删除或分支仍占空间 | 同事务删文章/访问/引用并保留最小资产清理状态，提交后幂等物理删除；例句留表、下次点击生成；实际计量与并发预留 | 正常集成验证事务回滚/提交后崩溃、删除重试、旧 worker 不复活、例句重建与实际 quota 释放；不成立须重新选择 |
| 缓存/保留边界 | 清音频误删学习文本或词义 | 音频可重建、lookup 快照独立；只有文章本体/专属资产/访问行随文章淘汰 | FK/cascade 审查；FIFO 不是 LRU，例句创建时间也参与排序 |
| 数据增长 | 个人解释/复习/用量不断增长，1 GB 免费 DB 终会不足 | 索引/字段测算、增长观察；音频清理不触及学习文本 | 没有授权静默淘汰学习数据或升级；不足时需重新决定 |
| 免费计算/出网 | 单次模型能跑仍可能月预算不够 | Hobby 实际硬件/月 CPU 与共享出网测算；空任务立即退出 | **TTS/Speak spike 及 staging 未完成**，不承诺 100 并发全部免费 |
| 调度份额 | 两环境全天运行超 5,000 次 | 只生产持续心跳，测试窗口开，计入所有团队项目 | 15 分钟周期含抖动/漏调，不能作为准时 SLA |
| 单点/恢复 | Free 无项目级 SLA/可靠每日备份 | 用户选择弱恢复，有限历史窗口/手动快照；恢复后对象引用对账 | **接受风险**；未测 RPO/RTO，旧 24 小时目标不保证 |
| 身份/权限 | 客户端藏按钮不足，签名 URL 泄露窗口 | 服务端 session/成员/owner；私有对象短期 URL，日志不含令牌 | staging 跨用户/取消成员/过期 URL 检查 |
| 输入/来源安全 | 抓取 SSRF、HTML 注入、提示注入及无效选项 | 来源白名单/跳转限制、正文渲染转义；Zod+语义校验、AI 无任意工具权限 | 正式来源条件未批准；接入前核对 |
| 预览/密钥 | 生产数据进入 PR，未审代码读取共享 key | 测试种子派生、独立凭据；可信工作流静态/动态配置核对 | 仅 OpenAI key 按用户要求共享，供应商限速影响共用 |
| 代码边界 | Next 服务端能力容易绕过模块规则 | 路由/application/模块端口、server-only、dependency-cruiser 规则 | scaffold 必须适配 React/Node 规范及检查 |
| 部署/回滚 | main 直接上生产绕过验收、回滚不兼容 SQL | staging 自动、标签后手动生产；关闭另一自动发布路径；扩展/收缩迁移 | 无仓库/资源/工作流，实施后演练 |
| 视觉/设备 | 自有浮层焦点或手机选区/后台音频不可靠 | 设计稿先确认、Storybook 状态、Playwright 截图/流程、真实手机 | 尚无 UI 稿/样音或设备证据 |
| 诊断/成本 | 免费 trace 短留存/暂停，费用无回执被当零 | OTel 采样+JSON+持久 usage；unknown 状态，手动恢复 tracing | 免费配额不是长期审计库；没有付费增强/费用看板 |
| 演进/迁移 | 为未来预建平台、假称已有迁移需求 | 仅保留适配端口/API与任务版本；新项目无旧系统迁移 | 触发容量证据后走 change，不先搭额外平台 |
