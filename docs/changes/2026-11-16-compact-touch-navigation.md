# 紧凑图标、触控浮层与跨页播放

- 日期：2026-11-16（America/Toronto）
- 来源：用户对第三版触控与桌面预览的直接反馈及两次补充
- 状态：规则已记录，第四版可见稿待审；无应用、认证或音频集成
- 定级：L2 / D0；替换未实现的导航/播放规则，现有模块和技术平台能容纳，无生产数据迁移
- 相关：REQ-001–002、007、010–012、015–016、019、022、028、036–037；ADR-0017展示方向不变

## 决定

所有布局只保留Articles与Vocabulary导航，移除Speak/Spell/Translate快捷菜单。唯一复习入口在Vocabulary。Vocabulary菜单右上红/黄圆点汇总三模式due/new任务数，同词不同mode分别计数，不受搜索/轮次筛选影响。数量与模式按钮采用相同服务端口径，可访问名称说明含义。

空间足够显示图标加文字，窄屏仅图标并保留可访问名称。手机Vocabulary导航不能换行，三模式按钮也不能拆词换行。触控每个词条下三模式各一条细边框信息组，模式图标、Round N及Next相邻；宽度够再加模式名称，不把三项拉到卡片两端。播放文章/Play all用三角图标。加载完毕显示All loaded状态文字，保留未加载完时的Load more按钮及最终加载焦点去向。

触控Articles使用来源/分类图标筛选及排序图标；Vocabulary使用三模式轮次图标筛选及排序图标。不再展开包含Sort标签和不一致原生下拉框的工具行。统一浮层包含筛选复选项/Apply，或排序单选项与升降序；以产品容器边界夹紧水平坐标，预留12px，适配尺寸变化与空间不足时的翻转。正式实现须覆盖320px、缩放、旋转、软键盘、长来源名称及焦点返回。

JC头像是电脑/手机共同账号入口，点开才显示Log out，移除旧侧栏底部/独立手机退出按钮。仍由Clerk实现真实登录退出，退出清个人客户端状态、不删服务器学习记录。

单题右上关闭X返回启动它的Vocabulary原状态/搜索/筛选/排序/页码/加载量/滚动与模式按钮焦点。已保存成绩只读，未提交关闭不计错，进行中或未知结果保留attempt ID核对，不把close当撤销。删除整行大题头和上一题编辑的规则保持。

篇末先回列表再进下一篇；页末先进入下一页再自动进首篇。Play all冻结完整匹配顺序，行播放从点击文章开始连续其后项目。队列保留原列表ordinal以恢复正确页码，访问更新不重排；删除项跳过，全部结束回列表停止。后台推进不依赖路由动画的500ms演示定时器，跨文手势限制仍须设备实测。

文本选择图标是原生长按/拖选之外的辅助入口，文章、解释浮窗、词卡例句、三种单题保持一致，可通过句段/起止词选择确认查词；未确认不调用AI，不默认查某个示例词。隐藏目标不能出现在选词选项中或被跨选；嵌套例句继续新建浮窗。
