# 列表、复习与输入方式设计修订

- 日期：2026-11-16
- 级别：L2需求调整 / D2详细设计调整；无应用代码，非技术架构重选
- 来源：用户对首轮设计的完整逐项反馈，含“鼠标操作和手指操作搞两个版本”

## 变了什么、为什么

用户要求更小字号、更高信息密度和更少无意义文案；鼠标以表格分页操作，触控以卡片连续加载，统一数据和业务。合并Articles/History、Vocabulary/Archive；补充全量搜索/多列排序/三模式轮次组合筛选；播放条仅阅读页呈现；连续播放经过列表再入下一篇；解释改为底部对齐的嵌套浮窗；新增词头独立音频缓存。单题移除侧栏/冗余提示，只显示本题必要信息和轮次。

## 影响

| 类别 | 内容 |
|---|---|
| 需求 | 更新REQ-001/003/006/007/010/011/015/019/022–025，新增REQ-035–038；同日直接用户要求优先于先前AI草案 |
| 架构 | ADR-0017扩展已有media缓存范围与输入展示约定，模块/平台/队列不变 |
| 代码 | 无应用代码；仅文档和聊天可交互设计稿 |
| 数据 | 目标source_icons、media.duration_ms、word_tts类型；visits原本已有唯一键无需变为append；无存量迁移 |

## 决定和待验证

字数只详情临时算；列表无时长读取；时长复用生成结果；图标建议bytea，不存Base64重复文本；RSS优先但先确认是否含全文及可使用条件。手指保留原生长按选区，直接滑动默认滚动；平板按输入/宽度适配并可选择布局。不能承诺任意屏幕高度/缩放下review永远无滚动，不用裁剪牺牲可访问性。具体修订稿仍待用户查看，未把其余首轮草案参数标记确认。
